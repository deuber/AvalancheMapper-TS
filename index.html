Avalanche Mapper TS

Upload a photo taken at an avalanche site and this reads the GPS coordinates straight out of the image's metadata and drops a pin on a topo map — built to make avalanche observation reports to places like the Sierra and Utah Avalanche Centers more accurate. No account, no upload to a server — everything happens in your browser. Source on GitHub.

Upload a photo

JPG, HEIC, PNG or TIFF, taken with location services on. Nothing leaves your browser — the file is read locally to extract its GPS tag, never uploaded anywhere.

Under the hood

A TypeScript rewrite of the original vanilla-JS version.

  • Strict TypeScript — strict, noUncheckedIndexedAccess, exactOptionalPropertyTypes; no any, no unchecked casts.
  • Typed trust boundary — EXIF output arrives as unknown and is narrowed into a discriminated union (gps | no-gps | error) handled by an exhaustive switch.
  • Tested — Vitest unit tests for coordinate parsing/formatting, plus an end-to-end test that writes GPS EXIF into a real JPEG and reads it back.
  • CI/CD — GitHub Actions type-checks, tests and builds with Vite on every push, then deploys to GitHub Pages.
  • Bugs fixed from v1 — lowercase s/w hemispheres ignored, PNG/HEIC GPS never read, no lat/lng range checks; see the README for the full debugging notes.
Runs entirely client-side — GPS extraction via exifr, mapping via Leaflet + OpenTopoMap (no API key required). Source: github.com/deuber/AvalancheMapper-TS
